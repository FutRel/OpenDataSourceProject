## Курсовой проект на основе открытых данных

Данный проект являет собой веб-приложение на основе открытых данных для визуализации статистической информации о социальном благополучии районов города Москва.

Приложение использует данные из различных открытых источников и отображает их на интерактивной карте 2GIS, предварительно разбивая их на кластеры при помощи метода k-means, обработка данных и реализация алгоритма осуществлена на PHP с сохранением данных в временной таблице на локальном сервере.

Также, существует страница для просмотра данных с различными фильтрами и умным поиском.
